Worksheet Studio

paste problems → typeset PDF
Input format 
Line 1        → title
Line 2        → subtitle (optional)
Problem 1.    → starts a problem
              (also: 1.  1)  Q1.  #1)
*Problem 5.   → starred challenge problem
(a) ... (b)   → lettered parts
Answer Key    → everything after goes to
                a boxed key on a new page
Math goes in $...$; write \$ for currency.
**bold** and *italic* may wrap $math$.

[graph] ... [/graph]    coordinate plane
  x: -5 to 5   y: 0 to 10   size: small
  y = 2x - 3 [red, label: $f$]
  y <= -x + 2         shaded inequality
  y = x + 3 for -3 <= x < 0   piecewise
  point A (1, 2)   segment P(0,0) to Q(3,4)
  polygon A(1,1) B(4,1) C(4,3)   circle (0,0) radius 3

[figure] ... [/figure]  to-scale geometry
  triangle ABC AB=8 angle A=50 angle B=60
  right triangle PQR legs 6 8
  parallelogram ABCD base 7 side 4 angle 65
  side AB 8 cm [ticks: 1]   angle C measure
  right angle DEA   point E foot D A B

| $x$ | 1 | 2 |       table (a |---| row
| $y$ |   |   |       under row 1 = header)

[grid 4] ... [/grid]          4-across drill grid
[columns 2] ... [/columns]    newspaper columns
